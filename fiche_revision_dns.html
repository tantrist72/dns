1. Principe du DNS

Le DNS traduit des noms faciles à retenir en adresses IP.

Client
→
Résolveur
→
Serveur DNS
→
Espace de noms
Exemple : titan.ciel.edu → 192.168.0.1

Résolveur

Partie du client qui demande une résolution de nom.

Serveur DNS

Reçoit la requête et cherche la réponse.

Espace de dénomination

Organisation hiérarchique des noms DNS.

2. Noms de domaine

Exemple : titan.ciel.edu

titan = hôte
ciel = SLD
edu = TLD

FQDN

Nom complet d’une machine : titan.ciel.edu.

Le point final représente la racine DNS.

Label

63 octets maximum.

Nom complet

255 octets maximum.

AFNIC

Gère notamment le domaine .fr.

4. Côté client Debian

/etc/hosts

Résolution locale nom ↔ IP.

/etc/hostname

Nom de la machine.

/etc/resolv.conf

Serveur(s) DNS utilisés.

Exemple de /etc/resolv.conf

nameserver 192.168.0.1
search ciel.edu

Ordre de résolution

Il se règle dans /etc/nsswitch.conf.

hosts: files dns
Ordre : d’abord /etc/hosts, puis le DNS.

6. Zones DNS de ton TP

named.conf.local

zone "ciel.edu" {
    type master;
    file "/etc/bind/db.ciel.edu";
};

zone "0.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192.168.0";
};

7. Vérification et tests

Vérifier la configuration

named-checkconf

named-checkzone ciel.edu /etc/bind/db.ciel.edu

named-checkzone 0.168.192.in-addr.arpa /etc/bind/db.192.168.0

Résultat attendu : OK

Redémarrer et vérifier

systemctl restart bind9
systemctl status bind9

ss -lntup | grep :53

Résolution directe

dig @192.168.0.1 titan.ciel.edu
dig @192.168.0.1 client1.ciel.edu
dig @192.168.0.1 client2.ciel.edu

Résolution inverse

dig @192.168.0.1 -x 192.168.0.1
dig @192.168.0.1 -x 192.168.0.2
dig @192.168.0.1 -x 192.168.0.101

8. Résolution Internet

Teste d’abord :

dig google.fr
Si ciel.edu fonctionne mais pas Internet, tu peux avoir besoin de configurer les forwarders dans named.conf.options.

Exemple de named.conf.options

options {
    directory "/var/cache/bind";

    recursion yes;

    forwarders {
        8.8.8.8;
        1.1.1.1;
    };
};

Les DNS à utiliser dépendent de ce qui est autorisé sur ton réseau scolaire.

Quelle différence entre zone directe et inverse ?

Directe : nom → IP. Inverse : IP → nom.

À quoi sert named.conf.local ?

À déclarer les zones personnalisées comme ciel.edu.

À quoi sert named.conf.options ?

À régler les options générales du serveur, notamment récursion et forwarders.

Quel port utilise DNS ?

Le port 53, en UDP et TCP.
